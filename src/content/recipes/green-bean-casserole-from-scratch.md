---
title: "Green Bean Casserole from Scratch"
emoji: "🫛"
tags: ["Side", "Vegetarian"]
time: 50
servings: 8
ingredients:
  - { qty: 1.5, unit: "lb", item: "green beans, trimmed and halved" }
  - { qty: 3, unit: "tbsp", item: "butter" }
  - { qty: 8, unit: "oz", item: "mushrooms, sliced" }
  - { qty: 2, unit: "", item: "garlic cloves, minced" }
  - { qty: 3, unit: "tbsp", item: "all-purpose flour" }
  - { qty: 1, unit: "cup", item: "vegetable or chicken broth" }
  - { qty: 1, unit: "cup", item: "milk" }
  - { qty: 0.75, unit: "tsp", item: "salt" }
  - { qty: 0.25, unit: "tsp", item: "black pepper" }
  - { qty: 1.5, unit: "cup", item: "crispy fried onions" }
steps:
  - "Heat oven to 375°F. Boil green beans in salted water 4 minutes, then drain and rinse with cold water."
  - "Melt butter in a large skillet over medium-high. Cook mushrooms until browned, 6–8 minutes, then add garlic for 30 seconds."
  - "Sprinkle in flour and stir 1 minute. Slowly stir in broth and milk and simmer until thick, 3–4 minutes. Season with salt and pepper."
  - "Fold in the beans and half the fried onions. Spread in a 2-quart baking dish."
  - "Bake 20 minutes, top with the remaining onions, and bake 5 minutes more."
