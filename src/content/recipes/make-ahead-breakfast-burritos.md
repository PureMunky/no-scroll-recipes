emoji: "🌯"
tags: ["Breakfast", "Make-ahead"]
time: 40
servings: 8
ingredients:
  - { qty: 1, unit: "lb", item: "breakfast sausage" }
  - { qty: 2, unit: "cup", item: "frozen diced hash browns" }
  - { qty: 10, unit: "", item: "eggs" }
  - { qty: 0.5, unit: "tsp", item: "salt" }
  - { qty: 1.5, unit: "cup", item: "shredded cheddar" }
  - { qty: 8, unit: "", item: "large flour tortillas" }
  - { qty: 0.5, unit: "cup", item: "salsa" }
steps:
  - "Brown sausage in a large skillet, breaking it up, about 8 minutes. Move to a bowl, leaving the fat."
  - "Cook hash browns in the same pan until crisp, about 8 minutes. Add to the sausage."
  - "Whisk eggs with salt and scramble over medium-low until just set."
  - "Fill each tortilla with eggs, sausage and potatoes, cheese and a spoon of salsa. Roll tightly, tucking in the ends."
  - "Eat now, or cool, wrap each in foil, and freeze in a bag."
tip: "To reheat from frozen: remove foil, wrap in a damp paper towel, and microwave 2–3 minutes, flipping halfway."
