---
title: "2-Minute Chocolate Mug Cake"
emoji: "☕"
tags: ["Dessert", "Kid-friendly", "Vegetarian"]
time: 5
servings: 1
ingredients:
  - { qty: 4, unit: "tbsp", item: "all-purpose flour" }
  - { qty: 2, unit: "tbsp", item: "unsweetened cocoa powder" }
  - { qty: 3, unit: "tbsp", item: "sugar" }
  - { qty: 0.25, unit: "tsp", item: "baking powder" }
  - { qty: 1, unit: "pinch", item: "salt" }
  - { qty: 3, unit: "tbsp", item: "milk" }
  - { qty: 2, unit: "tbsp", item: "neutral oil" }
  - { qty: 0.25, unit: "tsp", item: "vanilla" }
  - { qty: 1, unit: "tbsp", item: "chocolate chips" }
steps:
  - "Stir flour, cocoa, sugar, baking powder and salt in a large mug."
  - "Add milk, oil and vanilla and mix until smooth. Drop chips on top."
  - "Microwave 60–90 seconds, until risen and just set on top."
  - "Cool 1 minute before eating."
tip: "Microwaves vary — start checking at 60 seconds."
