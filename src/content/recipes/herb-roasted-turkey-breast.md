---
title: "Herb-Roasted Turkey Breast"
emoji: "🍗"
tags: ["Dinner", "Gluten-free"]
time: 150
servings: 8
ingredients:
  - { qty: 1, unit: "", item: "bone-in, skin-on turkey breast (6–7 lb), thawed" }
  - { qty: 4, unit: "tbsp", item: "butter, softened" }
  - { qty: 3, unit: "", item: "garlic cloves, minced" }
  - { qty: 2, unit: "tbsp", item: "chopped fresh herbs (sage, thyme, rosemary)" }
  - { qty: 2, unit: "tsp", item: "salt" }
  - { qty: 0.5, unit: "tsp", item: "black pepper" }
  - { qty: 1, unit: "cup", item: "chicken broth" }
steps:
  - "Heat oven to 425°F. Pat the turkey breast dry."
  - "Mash butter with garlic, herbs, salt and pepper. Loosen the skin and spread half underneath, the rest on top."
  - "Set skin-side up in a roasting pan and pour the broth into the pan."
  - "Roast 20 minutes, then lower to 350°F and roast 1¼–1¾ hours more, until the thickest part reads 165°F."
  - "Rest 20 minutes, then slice across the grain."
tip: "The right call for a smaller crowd — all the holiday flavor, half the time of a whole bird."
added: 2026-11-08
