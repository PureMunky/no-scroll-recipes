---
title: "Extra-Smooth Hummus"
emoji: "🫘"
tags: ["Snack", "Vegetarian", "Gluten-free"]
time: 10
servings: 6
ingredients:
  - { qty: 1, unit: "can", item: "chickpeas (15 oz), drained" }
  - { qty: 0.25, unit: "cup", item: "tahini" }
  - { qty: 3, unit: "tbsp", item: "lemon juice" }
  - { qty: 1, unit: "", item: "garlic clove" }
  - { qty: 0.5, unit: "tsp", item: "salt" }
  - { qty: 0.5, unit: "tsp", item: "ground cumin" }
  - { qty: 3, unit: "tbsp", item: "ice water" }
  - { qty: 2, unit: "tbsp", item: "olive oil, plus more to serve" }
steps:
  - "Blend tahini and lemon juice in a food processor 1 minute until whipped."
  - "Add garlic, salt and cumin, then chickpeas, and blend 2 minutes."
  - "With the motor running, drizzle in ice water and oil until very smooth, about 2 minutes more."
  - "Spread in a bowl and drizzle with oil."
tip: "Blending the tahini and lemon first is what makes it fluffy."
