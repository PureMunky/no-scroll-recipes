tags: ["Breakfast", "Baking", "Vegetarian", "Make-ahead"]
time: 75
servings: 10
ingredients:
  - { qty: 3, unit: "", item: "very ripe bananas" }
  - { qty: 0.33, unit: "cup", item: "butter, melted" }
  - { qty: 0.75, unit: "cup", item: "sugar" }
  - { qty: 1, unit: "", item: "egg" }
  - { qty: 1, unit: "tsp", item: "vanilla" }
  - { qty: 1, unit: "tsp", item: "baking soda" }
  - { qty: 0.25, unit: "tsp", item: "salt" }
  - { qty: 1.5, unit: "cup", item: "all-purpose flour" }
  - { qty: 0.5, unit: "cup", item: "chocolate chips or walnuts (optional)" }
steps:
  - "Heat oven to 350°F and grease a 9×5-inch loaf pan."
  - "Mash bananas in a large bowl, then stir in melted butter."
  - "Stir in sugar, egg and vanilla, then sprinkle baking soda and salt over and mix."
  - "Add flour and stir just until no dry streaks remain. Fold in chips or nuts."
  - "Bake 55–65 minutes, until a toothpick in the center comes out clean. Cool 10 minutes, then turn out."
tip: "The browner the bananas, the better the bread. Freeze overripe ones whole and thaw before using."
