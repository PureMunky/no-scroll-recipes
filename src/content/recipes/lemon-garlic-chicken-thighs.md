---
title: "Crispy Lemon-Herb Chicken Thighs"
emoji: "🍗"
tags: ["Dinner", "Gluten-free"]
time: 50
servings: 4
ingredients:
  - { qty: 8, unit: "", item: "bone-in, skin-on chicken thighs (about 3 lb)" }
  - { qty: 2, unit: "tbsp", item: "olive oil" }
  - { qty: 1, unit: "tsp", item: "salt" }
  - { qty: 0.5, unit: "tsp", item: "black pepper" }
  - { qty: 1, unit: "tsp", item: "garlic powder" }
  - { qty: 1, unit: "tsp", item: "dried thyme" }
  - { qty: 1, unit: "", item: "lemon, sliced" }
steps:
  - "Heat oven to 425°F. Pat chicken very dry."
  - "Rub with oil, salt, pepper, garlic powder and thyme."
  - "Arrange skin-side up on a sheet pan with lemon slices tucked around."
  - "Roast 35–40 minutes, until the skin is crisp and the thickest part reads at least 175°F."
  - "Rest 5 minutes and squeeze the roasted lemon over."
tip: "Thighs are safe at 165°F but get more tender at 175–185°F."
