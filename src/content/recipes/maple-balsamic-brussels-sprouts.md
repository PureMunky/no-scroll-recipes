---
title: "Maple-Balsamic Brussels Sprouts"
emoji: "🥬"
tags: ["Side", "Vegetarian", "Gluten-free"]
time: 35
servings: 6
ingredients:
  - { qty: 2, unit: "lb", item: "Brussels sprouts, trimmed and halved" }
  - { qty: 3, unit: "tbsp", item: "olive oil" }
  - { qty: 0.75, unit: "tsp", item: "salt" }
  - { qty: 0.25, unit: "tsp", item: "black pepper" }
  - { qty: 2, unit: "tbsp", item: "maple syrup" }
  - { qty: 1, unit: "tbsp", item: "balsamic vinegar" }
steps:
  - "Heat oven to 425°F."
  - "Toss sprouts with oil, salt and pepper and arrange cut-side down on a sheet pan."
  - "Roast 20–25 minutes, until deeply browned underneath and tender."
  - "Whisk maple and balsamic, drizzle over the hot sprouts, and toss."
tip: "Cut-side down against the hot pan is what gets the caramelized edges."
added: 2026-11-08
