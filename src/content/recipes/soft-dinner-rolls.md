title: "Soft Dinner Rolls"
emoji: "🥯"
tags: ["Side", "Baking", "Vegetarian", "Make-ahead"]
time: 150
servings: 15
ingredients:
  - { qty: 1, unit: "cup", item: "milk, warmed to about 110°F" }
  - { qty: 2.25, unit: "tsp", item: "instant yeast" }
  - { qty: 0.25, unit: "cup", item: "sugar" }
  - { qty: 1, unit: "", item: "egg" }
  - { qty: 4, unit: "tbsp", item: "butter, softened, plus 2 tbsp melted for brushing" }
  - { qty: 1, unit: "tsp", item: "salt" }
  - { qty: 3.5, unit: "cup", item: "all-purpose flour, plus more as needed" }
steps:
  - "Stir milk, yeast and sugar in a large bowl. Add egg, softened butter, salt and 3 cups flour and mix into a shaggy dough."
  - "Knead 6–8 minutes, adding flour a spoonful at a time, until smooth and only slightly tacky."
  - "Cover and let rise in a warm spot until doubled, about 1 hour."
  - "Divide into 15 pieces, roll into balls, and set in a greased 9×13-inch pan. Cover and rise until puffy, 45 minutes. Heat oven to 375°F."
  - "Bake 18–20 minutes until golden. Brush with melted butter while hot."
tip: "Shape the day before, cover, and refrigerate overnight; let them sit out 1 hour before baking."
added: 2026-11-08
