  - { qty: 2, unit: "tsp", item: "baking powder" }
  - { qty: 0.5, unit: "tsp", item: "salt" }
  - { qty: 0.5, unit: "cup", item: "butter, melted" }
  - { qty: 2, unit: "", item: "eggs" }
  - { qty: 0.75, unit: "cup", item: "milk" }
  - { qty: 1, unit: "tsp", item: "vanilla" }
  - { qty: 1.5, unit: "cup", item: "blueberries" }
steps:
  - "Heat oven to 375°F and line a 12-cup muffin tin."
  - "Whisk flour, sugar, baking powder and salt in a large bowl."
  - "Whisk butter, eggs, milk and vanilla, then stir into the dry ingredients until just combined."
  - "Gently fold in blueberries and divide batter among the cups."
  - "Bake 20–24 minutes, until golden and a toothpick comes out clean."
tip: "Toss frozen berries in a spoonful of flour first so they don't sink or turn the batter purple."
