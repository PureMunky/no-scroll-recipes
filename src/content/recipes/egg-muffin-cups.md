  - { qty: 10, unit: "", item: "eggs" }
  - { qty: 0.25, unit: "cup", item: "milk" }
  - { qty: 0.5, unit: "tsp", item: "salt" }
  - { qty: 0.25, unit: "tsp", item: "black pepper" }
  - { qty: 1, unit: "cup", item: "finely chopped vegetables (peppers, spinach, onion)" }
  - { qty: 1, unit: "cup", item: "shredded cheese" }
steps:
  - "Heat oven to 350°F and grease a 12-cup muffin tin well."
  - "Whisk eggs, milk, salt and pepper."
  - "Divide vegetables and cheese among the cups, then pour egg mixture over until each is about ¾ full."
  - "Bake 20–22 minutes, until puffed and set in the center."
  - "Cool 5 minutes before removing. Refrigerate up to 4 days."
tip: "Add cooked bacon or sausage if you're not keeping it vegetarian."
